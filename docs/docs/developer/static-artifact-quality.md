# Static artifact quality criteria

A self-contained page built from connected data is usable when:

1. Every stated figure has the requested population, grain, scope, unit and reference. Totals reconcile with the source rows and with any detail shown on the page. Missing data and unresolved relationships are labelled as such, never displayed as zero.
2. Controls change the promised content, and requested charts, maps, tables and details are reachable and readable. A page that draws only after a user action must still explain how to reach it.
3. The first view answers the request, and desktop and phone layouts keep labels, values and controls readable without clipping or overlap.
4. Geographic marks use source coordinates or an unambiguous maintained lookup. Approximate or unresolved positions are labelled; motion is used only when requested and respects reduced motion.
5. Publishing the page does not expose credentials or private source rows that the user did not ask to share.

These are product criteria. Benchmark checks can provide evidence for them, but a score alone cannot establish them.
